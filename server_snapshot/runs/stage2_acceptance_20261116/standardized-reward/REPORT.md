# 预测reward标准化修改与固定候选复验

用户授权先标准化，再检查reward区分度。更新正式预测评分为train_fit_zscore_energy_v2；拟合、求解使用原物理量，Rfit、稀疏惩罚0.2、三档lambda不变。未训练、未追加生成、未访问Cylinder测试集。

## 实现

预测与真实目标均按冻结的训练可见帧均值、标准差作z-score。SSE_z=sum_c SSE_c/std_c²；E_z=sum((target_c-mean_c)/std_c)²；Rpred=1/(1+SSE_z/E_z)。均值不会改变误差差值，但会改变目标归一化平方和。

均值：[0.22464685767409892, -1.8300814816805758e-06, -0.05325762481567411]；标准差：[0.1272155154649305, 0.10090604038531958, 0.2841859501978362]。

统计量来自原审计manifest中的92条轨迹train_fit可见去重帧，未用验证/测试重新估计；本轮只缩小读取窗口做复验，不重新估计全局统计量。NPZ兼容读取器也提供train_fit-only均值/尺度并缓存。缺失或无效统计量明确报错，不以零均值静默代替。

标准化后各通道同样大小的标准差单位误差具有相同SSE贡献；不保证某一个窗口的目标平方和占比正好各1/3。本窗口标准化目标平方和占比为u69.15%、v2.23%、p28.62%，此前原始压力占93.32%。当前占比反映该窗口相对全局训练均值的状态差异，已经不受通道单位变换影响。

## 验证与结论

26项组件/评分测试通过，包括通道独立单位变化与平移不变性、同等标准化误差在三个通道得到相同评分、无效mask不参与统计、统计量不被未来目标修改；现有fit→forecast→score与保存恢复测试同样通过。七个真实候选的Rfit与原审计一致，评分公式独立重算一致。

**结论：标准化已实现且验证，但原有1/(1+相对目标平方和误差)函数在短时预测上仍然饱和，不能据此声称reward已充分区分有效动力学。** 下一步若修改相对持续预测分数，需要用户决定；本轮没有修改。正式SFT与搜索没有启动，旧reward回放结果标记为历史，不能与本版标准化分数直接合并。
