# 唯一保留的旧阶段 2 EQGPT 参考版本

此目录是后续改造起点，模型架构、生成算法和解析源码未修改，旧任务接口仍限定两变量 u/v、两方程。未开始三变量改造或训练。

- 主代码：`layout/ast_bpe_multifield_v4/generator_search_optimized.py`。
- 原搜索实际使用的两方程数量采样器：`layout/ast_bpe_multifield_v4/two_equation_sampling.py`。它限制方程数，不是新的三方程实现。
- 词表：compact AST-BPE，总 token ID 300，含 PAD/EOS/BOS。
- 架构：d_model768，d_ff2048，6 层、8 头，位置上限72。
- 训练语料：`training_corpus`，v5 系数自由 PDE 语料，200 个 parent 公式、136 个来源组；编码后1264条，训练1096、验证168。来源组和 parent 不跨训练/验证。
- 检查点：`checkpoint/model.pt`，与语料编码文件及词表的 SHA-256 完全匹配。服务器保存权重；本地仅镜像源码、语料及清单，不另下载权重。
- 数值和 tokenizer 共享依赖放在 `layout` 中。CPython3.12 Linux 本地编译缓存原样保留；若在其他环境重建，需要匹配 Python 头文件。

选择该版本是因为它是现存可完整核对的 PDE 模型—词表—语料组合。后来的 base100 模型使用混合 ODE 语料，不属于这一 PDE 组合，不能仅按日期选为新主实验的基座。

`REFERENCE.json` 固定源文件和资产校验值。旧版训练脚本只作历史参考，尚未落实新计划的全部训练设置；禁止将其等同于新版三变量主实验。

旧目录只留下指向此目录中必要共享模块的兼容软链接；不保留旧实验入口与分支的重复源码。这样不会修改依赖这些共享模块的 baseline／阶段3源码。

语料本身含160个两变量、32个三变量和8个四变量系统，空间轴均为x/y。旧流程的两方程计数采样器及默认u/v解析接口限制了当前任务范围；这不等于Transformer只能表示两个变量。本轮未重命名变量或扩展接口。
